# North Star Bakery Website

This is a simple multi-page website built for **North Star Bakery** for a web development class project. 

The website uses HTML and CSS. It is built to work well on both mobile phones and desktop screens so local customers can easily check bakery items and store details.

## Pages Included

* **Home (`index.html`):** Welcome message, store hours, audio clip, and featured item of the week.
* **Products (`products.html`):** Bakery items, descriptions, and price ranges.
* **About Us (`about.html`):** The story of the bakery, sourcing details, and a short video clip.
* **Contact (`contact.html`):** Store location details and a simple pre-order request form.

## Future Plans

This project is currently work in progress. The basic design and layout are done, but I plan to add JavaScript later to make the site interactive (like form validation and menu filters).
